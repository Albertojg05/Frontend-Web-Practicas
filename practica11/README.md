# Frontend-Web-Practicas

## PRACTICA 11 - Componentes con TypeScript puro

1. ¿por qué el nombre de una etiqueta propia debe llevar guion?
Para evitar colisiones con las etiquetas HTML estándar (actuales o futuras). El guion le indica al navegador que se trata de un componente personalizado creado por ti y no de una etiqueta nativa como <"div"> o <"button">.
